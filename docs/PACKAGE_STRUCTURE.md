# Package structure

| Workspace                   | Responsibility in current work             | Current boundary                                                                                                                                                     |
| --------------------------- | ------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `apps/desktop`              | Angular renderer and Electron shell        | Renderer uses the narrow preload; Electron ESM main and workers own filesystem access, analysis/graph lifecycle, and JSON persistence; preload is sandboxed CommonJS |
| `apps/cli`                  | Commander executable                       | Depends on shared and core; currently version/help only; no scan or analysis command                                                                                 |
| `packages/shared`           | Contracts and Zod schemas                  | Project, import, settings, scan, analysis, and graph DTO/results/progress/history; no application dependencies                                                       |
| `packages/core`             | Scanner, static analysis, and graph engine | Framework-independent; uses narrow filesystem/parser interfaces; Graphology instances stay private and graph data is in-memory only                                  |
| `packages/language-support` | Language parser implementations            | TypeScript Compiler API parser for TypeScript/TSX/JavaScript/JSX; no Electron or Angular dependency                                                                  |
| `packages/database`         | Drizzle SQLite boundary                    | No driver, tables, migrations, or SQLite persistence yet                                                                                                             |
| `packages/export`           | Export format contracts                    | No bundle or viewer generation yet                                                                                                                                   |
| `packages/ai`               | Optional provider contract                 | No provider, credentials, or network behavior                                                                                                                        |

Project registrations, settings, and bounded scan-history summaries are local JSON files in Electron `userData`, accessed through interfaces in `apps/desktop/electron/services`. The latest full scan result is held in process memory for analysis; source text, static-analysis results, and the project-keyed latest graph are transient and are not persisted. The `packages/database` foundation is not used for graph storage or the current persistence layer; no SQLite/Drizzle graph schema or migration was added in Phase 5.

Workspace packages emit ESM JavaScript and TypeScript declarations to their ignored `dist/` directories. Package `exports` point to those build outputs. Electron main/worker output is ESM so it can consume workspace packages by their ESM exports; the sandboxed Electron preload is bundled to `preload.cjs`. Root build scripts build shared/core/language-support before consumers. Renderer and Electron TypeScript configurations remain separate to avoid mixing browser globals and Node/Electron types.
